# NodeGram brand guide

## Brand idea

NodeGram is the dependable bridge between constrained application infrastructure and the official Telegram Bot API. The identity combines connected nodes, a forward-moving bridge, and a subtle paper-plane silhouette without copying Telegram's trademarked mark.

## Name and language

- Product: **NodeGram**
- Tagline: **Telegram reaches your code.**
- Descriptor: **Secure serverless Bot API gateway**
- Attribution: **An open-source project by [NODE Group](https://www.nodegroup.ir/).**
- Persian descriptor: **درگاه امن و سرورلس برای Telegram Bot API**

Use “NodeGram” as one word with capital N and G. Do not use “Nodegram,” “NODEGRAM,” or “Node Gram” except where an all-caps interface label is visually necessary.

## Palette

| Token       | Hex       | Role                                           |
| ----------- | --------- | ---------------------------------------------- |
| Midnight    | `#07111F` | Primary dark background and wordmark           |
| Deep node   | `#0D1C2E` | Elevated dark surfaces                         |
| Signal cyan | `#21C4D6` | Connectivity, routes, successful transport     |
| NODE orange | `#FF6B35` | Brand signature, calls to action, active nodes |
| Cloud white | `#F7FAFC` | Reversed type and high-contrast nodes          |
| Steel       | `#526173` | Secondary text on light backgrounds            |
| Mist        | `#9FB0C3` | Secondary text on dark backgrounds             |

Orange is the signature accent; cyan describes the connection. Avoid large orange/cyan gradients in body UI.

## Typography

Use Inter for Latin interfaces and Vazirmatn for Persian/RTL interfaces. Fall back to the system sans-serif stack. Product headers should be strong but not futuristic; technical documentation should prioritize readability.

## Assets

- `icon.svg`: square avatar, favicon source, and compact mark
- `logo.svg`: primary mark on white/light surfaces
- `logo-reversed.svg`: mark on dark surfaces
- `cover.svg`: 2:1 GitHub/social preview with exact editable typography
- `nodegram-cover-background.png`: generated abstract campaign artwork without text; use as an optional hero or campaign background

Maintain clear space around the logo equal to one-quarter of the icon's height. Do not recolor individual nodes, add Telegram or DigitalOcean logos, rotate the mark, add glow to the wordmark, or place the light logo on a low-contrast image.

## Voice

Clear, calm, pragmatic, and security-aware. Explain hard platform limits directly. Avoid political claims, promises of anonymity, “unblock everything” language, or claims of affiliation with infrastructure providers.
