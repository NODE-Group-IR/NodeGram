# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a vulnerability

Report security issues privately to NODE Group. Do **not** open a public GitHub issue that contains:

- client API keys
- bot tokens
- chat IDs or message contents
- production Function URLs paired with live credentials

Email or contact channels: see [https://www.nodegroup.ir/](https://www.nodegroup.ir/) for current security contact information.

Include:

- NodeGram version / commit
- DigitalOcean runtime (`nodejs:22`)
- Reproduction steps without live secrets (use placeholders)
- Impact assessment

We aim to acknowledge reports within 7 days.

## Safe disclosure content

Use placeholders such as `ng_live_replace_me` and `000000000:EXAMPLE_BOT_TOKEN_REPLACE_ME_NOT_REAL`.
